評估、長上下文、延遲切塊與安全

RAG 評估讓調整有憑據，長上下文 vs RAG 幫你選架構，延遲切塊讓片段向量帶有全文脈絡，RAG 安全提醒你知識庫也是攻擊面。共 8 題，每堂各 2 題。

涵蓋課程：RAG 評估、長上下文 vs RAG、延遲切塊、RAG 安全。選項順序每次都會重新排列；最佳成績只存在你的瀏覽器裡。

🧩 開考前，先快速回顧

RAG 評估先有評估集，檢索與生成分開量：召回與精確看檢索，忠實度與答案相關性看生成；指標是診斷，不是目的。 回到這一堂 →
長上下文 vs RAG資料量、問題型態、更新頻率與成本會指向不同答案；小而穩的資料可全文，大而常變的單點查找適合 RAG，也可用混合路由。 回到這一堂 →
延遲切塊先讓長上下文嵌入模型讀完整份文件，再依邊界對 token 向量平均池化；不改文字、不加 LLM，但需要能輸出 token 向量的模型。 回到這一堂 →
RAG 安全知識庫投毒與間接提示注入；用入庫分級、檢索過濾、輸出檢查多層防禦，沒有單一防線擋得住所有攻擊。 回到這一堂 →
